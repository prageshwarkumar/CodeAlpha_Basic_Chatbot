# CodeAlpha Basic Chatbot

An advanced rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Greeting and conversation handling
- User name recognition
- Date and time information
- Random programming jokes
- Basic mathematical calculations
- Fuzzy text matching
- Multiple predefined chatbot responses
- Chat history saved in a text file
- English and Hindi phrase support

## Technologies Used

- Python
- Random Module
- Regular Expressions
- Datetime Module
- Difflib Module

## How to Run

1. Install Python on your computer.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python chatbot.py
```
